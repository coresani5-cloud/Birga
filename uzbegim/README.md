# Uzbegim — fast food sayti (demo)

Bitta fayl: `index.html`. Brauzerda ochish kifoya, server shart emas.

- Bo'limlar: Biz haqimizda, Menyu, Aksiyalar, Vakansiyalar, Aloqa
- Kategoriya tablari: aylantirganda faol bo'lim belgilanadi
- Savat, promokodlar (UZBEGIM10, BEPUL, SALOM), buyurtma turi, buyurtma kuzatuvi
- UZ / RU tillari, tungi va kunduzgi rejim

Telefon, manzil, narxlar — namuna. Ular `index.html` ichidagi `T`, `P`, `BRANCHES` obyektlarida.
